# Abhishek Thumbar Portfolio Website

Static one-page portfolio for GitHub Pages. Open `index.html` directly in a browser or upload the full folder to a GitHub Pages repository.

## Folder Structure

- `index.html` - page sections, SEO metadata, contact links, and download buttons
- `css/styles.css` - visual design, responsive layout, colors, spacing, and animations
- `js/main.js` - editable project list, category filters, modal behavior, navigation, and reveal animations
- `assets/projects/` - 16 extracted JPG images from the PDF portfolio
- `assets/docs/portfolio.pdf` - downloadable PDF portfolio copy

## Easy Edits

- Update name, tagline, bio, and contact details in `index.html`.
- Update project titles, categories, descriptions, services, and image paths in `js/main.js`.
- Replace social links by changing the `href="#"` values in the contact section.
- Tune the neutral palette using the CSS variables at the top of `css/styles.css`.
